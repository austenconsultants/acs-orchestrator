Call Processing Flow

1
Call Initiation: Customer dials AustenTel number
PSTN Network
2
SIP Routing: Twilio receives and routes to FreeSWITCH
SIP Trunk → 10.152.0.77
3
IVR Processing: ACS-Voice handles initial routing
FreeSWITCH ESL
4
AI Activation: ACS-Voice-Agent joins for AI features
LiveKit Room Creation
5
Speech Recognition: Whisper converts speech to text
OpenAI Whisper API
6
LLM Processing: GPT-4o processes and generates response
OpenAI GPT-4o
7
Voice Synthesis: Cartesia converts text to speech
Cartesia TTS API
8
Audio Delivery: Response streams back to customer
LiveKit → FreeSWITCH → Twilio
