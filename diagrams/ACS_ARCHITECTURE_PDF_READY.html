Process Flows

📞 Call Processing Flow

1
Call Initiation
Customer dials AustenTel phone number
2
Telephony Routing
Twilio receives call and establishes SIP trunk to FreeSWITCH
3
IVR Processing
ACS-Voice handles initial menu and routing decisions
4
Room Creation
LiveKit creates WebRTC room and notifies agents
5
Agent Connection
ACS-Voice-Agent joins room via LiveKit SDK
6
Speech Recognition
Whisper STT converts customer speech to text
7
LLM Processing
GPT-4o processes text and determines response
8
Voice Synthesis
Cartesia TTS converts response to natural speech
9
Audio Delivery
Speech streams back through LiveKit to customer

🤝 Multi-Agent Collaboration

1
Request Analysis
ACS-Manager receives and analyzes complex project request
2
Task Breakdown
Manager identifies required expertise and creates task list
3
Agent Assignment
Delegates to ACS-Voice and ACS-Voice-Agent based on skills
4
Parallel Execution
Agents work concurrently on their specialized tasks
5
Integration
Manager coordinates results and ensures compatibility
6
Delivery
Complete integrated solution presented to user
